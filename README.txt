TastyHome — статический сайт (HTML, CSS, JS без сборки).

Как опубликовать на GitHub Pages:
1. Распакуйте архив.
2. В репозитории удалите старые файлы (или загрузите новые поверх).
3. Загрузите СОДЕРЖИМОЕ папки (index.html, about.html, папки css, js, img, recipe и остальные файлы) в корень репозитория.
4. Settings -> Pages -> ветка main, папка / (root).

Что заменить:
- В файлах about.html и во всех recipe/*.html адрес почты hello@example.com и адрес сайта https://YOUR-DOMAIN (или напишите ассистенту адрес — он пересоберёт сайт).
- Иконки: img/icons/icon-1-v3.png ... icon-5-v3.png (можно заменить своими файлами с теми же именами).
- Фото блюд: img/<id>.jpg (например img/borsch.jpg).
- Рецепты и тексты — в HTML-файлах папки recipe/.
